================================================================================
LiFi PoC BREADBOARD — SIMULATION NOTES
================================================================================

Preset file       : presets/lifi_poc_breadboard.json
Pipeline          : cosim/pipeline.py
Python engine     : cosim/python_engine.py
Reference build   : Two ESP32s + 5mm white LED + small PV panel + TL072 dual-stage

================================================================================
1. SIMULATION FLOW (TX -> Channel -> RX -> Noise -> Demod -> BER)
================================================================================

The orchestrator (cosim/pipeline.py::SimulationPipeline) routes this preset to
the Python engine because `simulation_engine == "python"`. No SPICE binary is
spawned for this preset.

Each Simulate click executes the following pipeline:

  STEP 1  Transmitter
          - Generate a PRBS-7 bit sequence of length n_bits.
          - Build a time axis at the engine's sample rate.
          - Apply PWM_ASK modulation:
              I_DC      = bias_current_A * 1000     (mA, for the modulator math)
              level_hi  = I_DC * (1 + modulation_depth)
              level_lo  = I_DC * (1 - modulation_depth)
              carrier   = square wave at carrier_freq_hz, 50% duty
              I_tx(t)   = level_lo + (level_hi-level_lo) * bit(t) * carrier(t)
              P_tx(t)   = led_gled * I_tx(t)
          - Implementation: cosim/modulation.py::_modulate_pwm_ask
          - The PWM brightness envelope (pwm_freq_hz = 10 Hz) is treated as
            constant "ON" inside the data window; its duty cycle would scale
            BER analytically but does not change the per-bit waveform.

  STEP 2  Optical channel
          - Lambertian emission with order m derived from led_half_angle_deg:
              m = -ln(2) / ln(cos(half_angle))
          - Channel gain to the receiver aperture:
              G_ch = (m+1)/(2*pi) * cos^m(tx_angle) * (A_rx/d^2)
                     * cos(rx_tilt) * rect(FoV)
            beer_lambert_enabled=false here, so no exponential atmospheric term.
          - Implementation: cosim/channel.py::OpticalChannel.propagate
          - n_reflections = 0 means LOS only (no multipath ray addition).

  STEP 3  Photodetection
          - I_ph(t) = sc_responsivity * G_ch * P_tx(t).
          - pv_ode_enable=false here, so the simulator uses the linear
            responsivity model rather than the PV diode ODE.
          - Implementation: cosim/python_engine.py (receiver_optical_to_current).

  STEP 4  Noise injection (6-source model, 5 enabled)
          - Bandwidth used for noise integration: data_rate_bps / 2 = 500 Hz.
          - Per-source variances summed into a time-domain Gaussian noise
            sample and added to I_ph.
          - Implementation: cosim/noise.py::NoiseModel.generate_time_domain.
          - Source enables in this preset:
              shot       : ON  (2*q*(I_ph+I_dark)*Bn)
              thermal    : ON  (4kT*Bn / R_load)
              ambient    : ON  (2*q*I_ambient*Bn from 200 lux background)
              amplifier  : ON  (e_n^2 + (i_n*Z_in)^2)*Bn  with TL072 numbers
              ADC        : ON  (V_LSB^2/12 input-referred)
              processing : OFF (no comparator/threshold jitter on this build)

  STEP 5  Receiver analog chain  (topology: amp_slicer)
          - V_sense(t) = I_ph_noisy(t) * r_sense_ohm
                       = I_ph_noisy * 1 MOhm
          - Amplifier gain comes from ina_gain_dB:
              gain_linear = 10^(27.23/20) ~ 23
            which matches the TL072 stage (non-inverting, 1+22k/1k = 23).
          - V_rx(t)   = V_sense(t) * gain_linear
          - bpf_stages = 0, so no band-pass filtering is applied.
          - rx_chain_enable=false and rx_topology="amp_slicer" so the full
            INA -> BPF -> Comparator chain is bypassed.
          - notch_freq_hz=null -> no notch (60 Hz mains rejection is OFF).
          - Implementation: cosim/python_engine.py::run_python_simulation
            (lines 224-240, the "elif topology == 'amp_slicer'" branch).

  STEP 6  Demodulation
          - PWM-ASK demod: rectify, low-pass to the bit rate, then threshold
            decide one bit per symbol.
          - Implementation: cosim/modulation.py::_demodulate_pwm_ask
          - Recovered bits compared to bits_tx for BER.

  STEP 7  Metrics and output
          - BER = n_errors / n_bits
          - SNR_est_dB = 20*log10(<|V_rx_signal|> / <|V_rx_noise|>)
          - P_rx_avg_uW, I_ph_avg_uA, G_ch
          - Time-series streamed over WebSocket: time, P_tx, P_rx, I_ph, V_rx,
            bits_tx, bits_rx (subsampled to <= 4000 points for the UI).
          - Noise breakdown dict (per-source variances) is also returned.

================================================================================
3. WHAT THE SIMULATOR PRODUCES (per Simulate click)
================================================================================

Scalar metrics
  - ber               : measured bit error rate
  - ber_n_errors      : raw error count out of n_bits
  - ber_n_bits        : 20 here
  - snr_est_dB        : signal vs noise on V_rx
  - P_rx_avg_uW       : average received optical power
  - I_ph_avg_uA       : average photocurrent
  - G_ch              : Lambertian + geometry channel gain (linear)
  - noise_breakdown   : per-source variances (shot/thermal/ambient/amp/adc)

Time-series waveforms (subsampled to <=4000 pts for the UI)
  - time              : seconds
  - P_tx              : transmitted optical power
  - P_rx              : received optical power
  - I_ph              : photocurrent (post-noise if noise_enable=true)
  - V_rx              : pre-decision analog voltage (post-amp)
  - bits_tx, bits_rx  : transmitted vs received bit sequences

Derived in the UI
  - throughput        : data_rate_bps * (1 - ber)
  - eye opening, eye SNR, jitter sigma, edges (from V_rx + bits_tx)
  - Wilson 95% CI on BER given (errors, n_bits)
  - analytical BER companion (PWM_ASK isn't covered analytically in the
    current implementation, so the theory chip shows "-").


================================================================================
4. NOTES ON THIS PRESET vs THE GENERAL FRAMEWORK
================================================================================

- This is the "starter kit" preset: cheap parts, generous tolerances. It is
  intended to surface a working pipeline end-to-end before any of the harder
  presets (kadirvelu2021, correa2025) are tried.

- Because rx_topology="amp_slicer" and bpf_stages=0, the chain is intentionally
  shorter than the kadirvelu2021 reference design. There is no INA322 (TL072
  replaces it), no TLV7011 comparator (the ESP32 ADC + software thresholding
  takes its place), and no SMPS path on the energy side (dcdc_enable=false,
  rx_chain_enable=false).

- n_bits=20 is too few to claim a statistically meaningful BER. Use the
  "Precision run" button (or override n_bits via the CLI) for any number you
  want to put in a paper. With n_bits=20 the lowest measurable BER floor is
  ~1/n_bits = 5e-2; the Wilson 95% CI will be very wide.

- The Bode plot under "AC analysis" still works for this preset but only the
  sense-resistor + TL072 (no BPF) cascade is modeled there. Phase margin will
  read low because the amp_slicer path is open-loop, not a feedback system.

- KiCad export is NOT wired for this preset. Only `kadirvelu2021` has a
  systems/<name>_graph.py registered today. Adding one is mechanical (see
  PACKAGING.md / CLAUDE.md for the recipe).


================================================================================
5. HOW TO REPRODUCE A RUN ON THIS PRESET
================================================================================

CLI
  python cli.py pipeline --preset lifi_poc_breadboard

UI (Tauri or dev mode)
  Landing -> Builder -> click "Builder" CTA -> "Use a preset" -> pick
  "lifi_poc_breadboard" -> categories light up -> click Simulate.

Programmatically (Python)
  from cosim.system_config import SystemConfig
  from cosim.python_engine import run_python_simulation
  cfg = SystemConfig.from_preset("lifi_poc_breadboard")
  result = run_python_simulation(cfg)
  print("BER:", result["ber"], "SNR:", result["snr_est_dB"], "dB")
